# Синхроника — лендинг

Маркетинговый сайт PWA-приложения для синхронного плавания. Три аудитории: спортсменки, родители, тренеры.

- **Приложение:** https://nasuta.ru/Sinhronica/
- **Репозиторий приложения:** https://github.com/pavelnasuta/Sinhronica
- **Лендинг после включения Pages:** https://pavelnasuta.github.io/Sinhronica-website/ (если не назначен пользовательский домен)

## Публикация

Автоматическая сборка описана в `.github/workflows/deploy.yml`. При каждом коммите в `main` GitHub Actions:

1. Скачивает семь фирменных изображений из публичного репозитория приложения.
2. Собирает статическую папку `_site` с `index.html`, `robots.txt` и ассетами.
3. Публикует её через GitHub Pages.

**Первичная настройка:** открыть **Settings → Pages → Build and deployment → Source** и выбрать **GitHub Actions**, если не выбрано автоматически. В репозитории Actions должен быть разрешён запуск workflows.

Если скачивание графики не работает, проверьте публичную доступность `Sinhronica/main/public/`. Размещённый сайт после сборки хранит копии графики в `assets/` и не зависит от загрузки изображений из PWA при просмотре.

## Домен

При подключении собственного домена настройте **Settings → Pages → Custom domain** и DNS по инструкции GitHub. Ссылки на само PWA в `index.html` сейчас ведут на `https://nasuta.ru/Sinhronica/`; их нужно заменить только после отдельного переноса приложения.

## Данные и приватность

Лендинг не сохраняет спортивные записи. В PWA данные хранятся локально в браузере, без автоматической синхронизации между устройствами. Перенос PWA на другой домен **не переносит данные localStorage**.

В лендинге используется Яндекс.Метрика (ID из PWA) для измерения переходов в приложение. Для независимой статистики сайта замените счётчик в `index.html`.

## Редактирование

Сайт — один `index.html` без обязательной сборки Node.js. Цвета, тексты и мобильная адаптация находятся в файле. Визуальные решения основаны на `DESIGN.md` основного приложения.
